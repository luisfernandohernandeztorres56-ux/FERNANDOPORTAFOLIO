actividad 02 — lenguajes de diseño y programación

Lenguajes deDiseño & Prog.

Los lenguajes de diseño y programación son las herramientas fundamentales con las que los desarrolladores y diseñadores construyen el mundo digital: desde páginas web hasta aplicaciones complejas y experiencias visuales.

// sección 01

¿Qué son los Lenguajes?

Un lenguaje de programación es un sistema formal de instrucciones que permite comunicarse con una computadora para resolver problemas o crear aplicaciones. Por otro lado, los lenguajes de diseño son herramientas orientadas a definir la apariencia visual, la estructura y la experiencia de usuario en plataformas digitales. Ambos tipos son esenciales para construir el ecosistema digital moderno.

// sección 02

Diseño vs Programación

🎨 Lenguajes de Diseño

  • Se enfocan en la apariencia visual y la experiencia de usuario (UX/UI).
  • Controlan colores, tipografías, espaciados, animaciones e ilustraciones.
  • Ejemplos: CSS3, SASS, Figma (lenguaje de componentes), SVG.
  • Trabajan en la capa de presentación de una aplicación o sitio web.
  • Requieren sensibilidad visual y comprensión del comportamiento del usuario.

💻 Lenguajes de Programación

  • Se enfocan en la lógica, el comportamiento y el procesamiento de datos.
  • Controlan flujos de datos, bases de datos, algoritmos y servidores.
  • Ejemplos: JavaScript, Python, Java, C++, PHP, Ruby.
  • Trabajan tanto en el lado del cliente como en el servidor.
  • Requieren pensamiento lógico, matemático y resolución de problemas.

Marcado

HTML5

Lenguaje de marcado estándar para estructurar el contenido de páginas web. Define elementos como encabezados, párrafos, imágenes y enlaces.

Uso: Estructura web

Marcado

XML

Extensible Markup Language. Diseñado para almacenar y transportar datos de forma legible tanto para humanos como para máquinas.

Uso: Intercambio de datos

Estilos

CSS3

Hojas de estilo en cascada. Controla el diseño visual: colores, fuentes, márgenes, animaciones y diseño responsivo de páginas web.

Uso: Diseño visual web

Estilos

SASS

Preprocesador de CSS que añade variables, anidamiento, mixins y funciones para escribir hojas de estilo más potentes y mantenibles.

Uso: CSS avanzado

Scripting

JavaScript

El lenguaje de programación de la web. Permite crear interactividad, animaciones, validaciones y aplicaciones completas en el navegador.

Uso: Interactividad web

Backend

Python

Lenguaje de alto nivel, versátil y legible. Ampliamente usado en inteligencia artificial, ciencia de datos, automatización y desarrollo web.

Uso: IA / Data / Web

Backend

PHP

Lenguaje de servidor especializado en desarrollo web dinámico. Potencia plataformas como WordPress, Facebook (en sus inicios) y millones de sitios.

Uso: Servidores web

Compilado

Java

Lenguaje orientado a objetos, multiplataforma. Muy usado en aplicaciones empresariales, Android y sistemas de gran escala.

Uso: Empresarial / Android

Compilado

C++

Extensión de C con orientación a objetos. Usado en videojuegos, sistemas operativos, motores gráficos y software de alto rendimiento.

Uso: Sistemas / Videojuegos

Diseño

SVG

Scalable Vector Graphics. Formato XML para gráficos vectoriales en la web. Permite crear ilustraciones, íconos y animaciones escalables.

Uso: Gráficos vectoriales

Scripting

TypeScript

Superconjunto de JavaScript que añade tipado estático. Mejora la mantenibilidad y escalabilidad de proyectos JavaScript de gran tamaño.

Uso: Apps JS escalables

Backend

SQL

Structured Query Language. Lenguaje estándar para gestionar bases de datos relacionales: consultar, insertar, actualizar y eliminar datos.

Uso: Bases de datos
