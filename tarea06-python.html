¿Qué es Python?

Python es un lenguaje de programación de alto nivel, interpretado y de propósito general creado por Guido van Rossum en 1991. Es conocido por su sintaxis clara, legible y concisa, lo que lo convierte en uno de los lenguajes más populares del mundo. Se usa ampliamente en desarrollo web, ciencia de datos, inteligencia artificial, automatización y más.

conceptos clave

Fundamentos del Lenguaje

🐍
Variables y Tipos de Datos
En Python no se declara el tipo de una variable; se infiere automáticamente. Los tipos principales son int, float, str, bool, list, tuple, dict y set. Se asignan con el operador =.
📦
Listas, Tuplas y Diccionarios
Listas ([]) son mutables y ordenadas. Tuplas (()) son inmutables. Diccionarios ({}) almacenan pares clave: valor y son muy útiles para estructurar datos.
🔁
Estructuras de Control
Python usa if / elif / else para condiciones, y los bucles for (iteración) y while (condición). La indentación (espacios) define los bloques de código; no se usan llaves.
⚙️
Funciones
Se definen con def nombre():. Pueden recibir parámetros, valores por defecto y devolver resultados con return. Las funciones lambda (lambda x: x*2) son funciones anónimas de una sola línea.
🏛️
Programación Orientada a Objetos
Python soporta POO con class. Los objetos tienen atributos y métodos. Conceptos como herencia, encapsulamiento y polimorfismo son totalmente soportados. El constructor es el método __init__.
📂
Módulos y Librerías
Con import se importan módulos. Python cuenta con una biblioteca estándar enorme (math, os, datetime…) y librerías externas como NumPy, Pandas y Flask instalables con pip.
⚠️
Manejo de Excepciones
Los errores se gestionan con bloques try / except / finally. Esto permite que el programa continúe ejecutándose aun cuando ocurra un error inesperado, mejorando la robustez del código.
📖
Comprensiones de Lista
Sintaxis compacta para crear listas: [x*2 for x in range(5)]. También existen comprensiones de diccionarios y conjuntos. Son más eficientes y legibles que los bucles equivalentes.
🧠
Decoradores
Son funciones que modifican el comportamiento de otra función. Se aplican con @nombre_decorador encima de la función. Muy usados en frameworks como Flask para definir rutas web.

Ejemplo: Clase y Objetos (POO)

class Alumno:
    def __init__(self, nombre, grado):
        self.nombre = nombre
        self.grado  = grado
        self.notas  = []

    def agregar_nota(self, nota):
        self.notas.append(nota)

    def promedio(self):
        return sum(self.notas) / len(self.notas)

    def __str__(self):
        return f"{self.nombre} | Grado: {self.grado} | Promedio: {self.promedio():.1f}"


# Crear objeto
lf = Alumno("Luis Fernando", "5° Semestre")
lf.agregar_nota(9.5)
lf.agregar_nota(10)
lf.agregar_nota(9)
print(lf)
# Luis Fernando | Grado: 5° Semestre | Promedio: 9.5
