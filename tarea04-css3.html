// sección 02

Propiedades Esenciales

color

Color de texto

Define el color del texto. Acepta nombres, códigos HEX, RGB, HSL y RGBA con transparencia.

color: #cc0000;
color: rgba(0,0,0,.8);
background

Fondo

Controla el fondo: color sólido, imagen, degradado lineal o radial, con múltiples capas posibles.

background: linear-gradient(
  135deg, #000, #cc0000);
font-size

Tamaño de fuente

Define el tamaño del texto. Usa px, em, rem, % o vw/vh para tamaños responsivos y fluidos.

font-size: 1.2rem;
font-size: clamp(1rem,3vw,2rem);
margin / padding

Espaciado

Margin es el espacio exterior al elemento. Padding es el espacio interior entre el borde y el contenido.

margin: 0 auto;
padding: 16px 24px;
display

Tipo de visualización

Controla cómo se muestra el elemento: block, inline, flex, grid o none para ocultarlo.

display: flex;
display: grid;
border-radius

Bordes redondeados

Redondea las esquinas de un elemento. Con 50% crea círculos perfectos a partir de elementos cuadrados.

border-radius: 8px;
border-radius: 50%;
transition

Transición suave

Anima los cambios de propiedades CSS de forma fluida al interactuar con hover, focus u otros estados.

transition: all .3s ease;
transition: color .2s;
box-shadow

Sombra del elemento

Agrega sombras alrededor de un elemento. Admite múltiples sombras separadas por coma para efectos complejos.

box-shadow: 0 4px 20px
  rgba(0,0,0,.5);

Ejemplo Completo

styles.css 
/* Variables globales */
:root {
  --rojo: #cc0000;
  --fondo: #111314;
  --blanco: #f0eeeb;
}

/* Estilos del header */
header {
  background: var(--rojo);
  padding: 40px 20px;
  text-align: center;
  display: flex;
  flex-direction: column;
  align-items: center;
}

/* Título principal */
header h1 {
  font-size: 3rem;
  color: var(--blanco);
  text-shadow: 2px 2px 0 rgba(0,0,0,.3);
}

/* Cards del portafolio */
.card {
  background: var(--fondo);
  border-radius: 10px;
  box-shadow: 0 6px 24px rgba(0,0,0,.5);
  transition: transform .25s ease;
}

.card:hover {
  transform: translateY(-6px);
  box-shadow: 0 14px 36px rgba(204,0,0,.3);
}
