Guía RápidaHTML 5

HyperText Markup Language 5 es el estándar mundial para estructurar contenido en la web. Con HTML defines el esqueleto de cualquier página: su texto, imágenes, vínculos y formularios.

⚡ Versión 5 — Estándar W3C

// sección 01

Estructura Base de un Documento

<!DOCTYPE html>
<html lang="es">
  <head>
    <meta charset="UTF-8"/>
    <meta name="viewport" content="width=device-width, initial-scale=1.0"/>
    <title>Mi primera página web</title>
  </head>
  <body>
    <!-- Aquí va el contenido visible de la página -->
    <h1>¡Hola, mundo!</h1>
    <p>Mi primer párrafo en HTML.</p>
  </body>
</html>

// sección 02

Etiquetas Esenciales

<h1> – <h6>

Encabezados

Define los títulos de la página. H1 es el más importante y H6 el menos. Solo debe existir un H1 por página.

<p>

Párrafo

Agrupa texto en bloques de párrafo. Es el elemento más común para presentar texto en una página web.

<a>

Enlace / Hipervínculo

Crea un enlace a otra página, sección o recurso. Usa el atributo href para indicar el destino del enlace.

<img>

Imagen

Inserta una imagen en la página. Requiere src para la ruta y alt para el texto alternativo accesible.

<div>

Contenedor

Elemento contenedor genérico sin significado semántico. Se usa para agrupar y aplicar estilos a bloques de contenido.

<span>

Contenedor en línea

Contenedor en línea sin significado semántico. Útil para aplicar estilos a fragmentos de texto dentro de un párrafo.

<ul> / <ol>

Listas

ul crea listas sin orden (bullets) y ol crea listas ordenadas (numeradas). Los elementos van dentro de etiquetas <li>.

<form>

Formulario

Define un formulario interactivo para recopilar datos del usuario, como nombres, correos o contraseñas.

<table>

Tabla

Organiza datos en filas y columnas. Usa tr para filas, th para encabezados y td para celdas de datos.

// sección 03

Etiquetas Semánticas HTML5

HTML5 introdujo etiquetas semánticas que describen el significado del contenido, mejorando la accesibilidad y el SEO.

<header>

Encabezado de la página o sección

<nav>

Menú de navegación principal

<main>

Contenido principal único

<section>

Sección temática del documento

<article>

Contenido independiente y reutilizable

<aside>

Contenido secundario o barra lateral

<footer>

Pie de página o sección

<figure>

Imagen con su descripción
