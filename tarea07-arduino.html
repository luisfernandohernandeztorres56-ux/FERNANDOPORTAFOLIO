¿Qué es Arduino?

Arduino es una plataforma de hardware y software de código abierto diseñada para facilitar la creación de proyectos electrónicos interactivos. Consiste en una placa con un microcontrolador y un entorno de desarrollo (IDE). Su gran fortaleza es el enorme ecosistema de sensores, módulos y actuadores compatibles, que permiten interactuar con el mundo físico.

Sensores y Hardware Compatible

① sensores

🌡️
Sensor de Temperatura y Humedad
Sensor ambiental
DHT11 / DHT22 son los más populares. Miden temperatura y humedad relativa. Se conectan a un pin digital y requieren la librería DHT.h. El DHT22 tiene mayor precisión (±0.5°C) que el DHT11 (±2°C).
📡
Sensor Ultrasónico HC-SR04
Sensor de distancia
Mide distancias de 2 cm a 400 cm usando ondas ultrasónicas. Pines: VCC, GND, Trig (disparo), Echo (respuesta). Fórmula: distancia = tiempo × 0.034 / 2 cm.
☀️
Sensor de Luz LDR
Sensor fotoeléctrico
La fotorresistencia cambia su resistencia según la intensidad de luz. Se conecta en divisor de voltaje con una resistencia fija a un pin analógico (A0–A5). Valores: oscuridad = alto, luz = bajo.
🏃
Sensor de Movimiento PIR
Sensor de presencia
Detecta movimiento infrarrojo de seres vivos. Tiene salida digital (HIGH/LOW). Pines: VCC, OUT, GND. Cuenta con potenciómetros para ajustar sensibilidad y tiempo de retardo.
💡
Sensor de Color TCS3200
Sensor óptico
Detecta el color de superficies mediante fotodiodos y filtros RGB + blanco. Convierte la intensidad de luz en frecuencia. Usado en robótica para seguir líneas de colores.
🔥
Sensor de Gas MQ-2 / MQ-7
Sensor químico
Detecta gases como humo, butano, propano, CO. Tienen salida analógica y digital. Requieren un tiempo de precalentamiento (~30 s). Ideales para sistemas de alarma.

② actuadores

⚙️
Servomotor SG90 / MG996R
Motor de posición
Gira en ángulos precisos (0°–180°). Controlado por señal PWM. Se usa la librería Servo.h. Cables: rojo (5V), marrón (GND), naranja/amarillo (señal). El MG996R es metálico y más torque.
🔄
Motor DC con Driver L298N
Motor de corriente continua
Los motores DC requieren un driver como el L298N para control de velocidad (PWM) y dirección. Puede manejar 2 motores simultáneamente. Alimentación externa recomendada: 6–12V.
🔊
Buzzer Pasivo y Activo
Actuador sonoro
El buzzer activo suena con solo aplicar voltaje. El pasivo requiere señal PWM (función tone()) y permite generar distintas frecuencias/melodías. Se conecta a cualquier pin digital.
🖥️
Pantalla LCD 16×2 (con I²C)
Módulo de visualización
Muestra texto en 2 filas de 16 caracteres. Con el módulo I²C solo se necesitan 2 cables de datos (SDA, SCL). Librería: LiquidCrystal_I2C.h.
💧
Relay de 5V
Control de cargas
Permite a Arduino controlar cargas de alto voltaje (110V / 220V AC) con señales de 5V. Pines: VCC, GND, IN. Módulos de 1, 2, 4 y 8 relays disponibles.
🌈
Tira LED RGB (NeoPixel WS2812B)
Actuador lumínico
LEDs RGB individualmente direccionables. Con la librería FastLED o Adafruit NeoPixel se controla cada LED con un solo pin de datos. Permiten efectos visuales complejos con poco código.

③ módulos de comunicación

📶
Módulo WiFi ESP8266 / ESP32
Comunicación inalámbrica
El ESP8266 y el ESP32 añaden conectividad WiFi (y Bluetooth en ESP32). Pueden usarse como shield o ejecutar código propio. Clave para proyectos IoT.
📲
Módulo Bluetooth HC-05 / HC-06
Comunicación Bluetooth
Permite comunicación serial inalámbrica con teléfonos y computadoras vía Bluetooth. El HC-05 puede actuar como maestro o esclavo; el HC-06 solo como esclavo. Comunicación a 9600 bps por defecto.
🏷️
Módulo RFID RC522
Identificación por radiofrecuencia
Lee y escribe tarjetas y llaveros RFID a 13.56 MHz. Protocolo SPI. Librería: MFRC522.h. Muy usado en sistemas de control de acceso y asistencia.

Pines del Arduino UNO R3

Pines Digitales D0–D13

Entrada/salida digital (HIGH = 5V, LOW = 0V). D3, D5, D6, D9, D10, D11 admiten PWM (~) para señales analógicas.

Pines Analógicos A0–A5

Lectura analógica de 0–5V con resolución de 10 bits (0 a 1023). También pueden usarse como digitales.

Alimentación 5V / 3.3V / VIN

5V: salida regulada. 3.3V: 150 mA máx. VIN: entrada de 7–12V para fuente externa. GND: tierra.

Pines I²C (SDA / SCL)

SDA = A4, SCL = A5. Protocolo serial de 2 hilos para múltiples dispositivos en el mismo bus.

Pines SPI (MOSI/MISO/SCK/SS)

D11 (MOSI), D12 (MISO), D13 (SCK), D10 (SS). Protocolo de alta velocidad para pantallas, SD cards, RFID.

Puerto Serial (TX / RX)

D0 (RX) y D1 (TX). Comunicación serie con PC y módulos como HC-05. Usados por el Serial Monitor.

Ejemplo: Sensor DHT11 + Pantalla LCD

// ──────────────────────────────────────────
//  Sensor DHT11 + LCD I2C en Arduino
// ──────────────────────────────────────────
#include <DHT.h>
#include <LiquidCrystal_I2C.h>

#define DHTPIN    2
#define DHTTYPE   DHT11

DHT dht(DHTPIN, DHTTYPE);
LiquidCrystal_I2C lcd(0x27, 16, 2);  // dirección I²C, 16 cols, 2 filas

void setup() {
  dht.begin();
  lcd.init();
  lcd.backlight();
  lcd.print("Temp y Humedad");
}

void loop() {
  float temp = dht.readTemperature();  // °C
  float hum  = dht.readHumidity();

  if (isnan(temp) || isnan(hum)) {
    lcd.setCursor(0, 1);
    lcd.print("Error sensor");
  } else {
    lcd.setCursor(0, 1);
    lcd.print("T:");
    lcd.print(temp, 1);
    lcd.print(" H:");
    lcd.print(hum, 0);
    lcd.print("%");
  }

  delay(2000);  // esperar 2 segundos entre lecturas
}
